# 🎨 Painting E-Commerce Website (MERN Stack)

A full-stack **Painting E-Commerce Platform** built using the **MERN Stack (MongoDB, Express.js, React, Node.js)** with modern features like secure authentication, coupon system, and **Razorpay payment integration**.

---

## 🚀 Features

### 🛍️ User Features

* Browse paintings by category
* View detailed product pages
* Add to cart & wishlist
* Secure checkout process
* Apply discount coupons
* Razorpay payment gateway integration
* Order history & tracking
* User authentication (Signup/Login/Logout)
* Password reset via email

---

### 🛠️ Admin Features

* Admin dashboard
* Manage products (Create, Update, Delete)
* Manage categories & brands
* View and update orders
* Manage users (make admin/delete)
* Create and manage discount coupons

---

## 🧱 Tech Stack

### Frontend

* React + Vite
* Tailwind CSS
* Redux Toolkit + Redux Persist
* Flowbite React
* Material UI

### Backend

* Node.js
* Express.js
* MongoDB (Mongoose)
* JWT Authentication
* bcryptjs (Password hashing)

### Other Tools & Services

* Cloudinary (Image uploads)
* Razorpay (Payments)
* Nodemailer (Emails)

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

---

### 2️⃣ Setup Backend

```bash
cd backend
npm install
```

Run backend:

```bash
npm run dev
```

---

### 3️⃣ Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

---

### 4️⃣ Setup Admin Panel

```bash
cd admin
npm install
npm run dev
```
